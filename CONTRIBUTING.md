# Участие в разработке (Contributing Guide)

Мы приветствуем предложения, исправления ошибок и дополнения для проекта **VisionVoiceOffline**!

---

## Правила участия

1. **Безопасность и автономность:** Проект ориентирован на 100% автономную работу. Предложения, требующие подключения к облачным API для распознавания речи или выполнения команд, отклоняются.
2. **Конфиденциальность пользователя:** Любые функции, читающие экран, пароли, перехватывающие ввод с клавиатуры или требующие Root-прав, запрещены архитектурными принципами проекта.
3. **Изоляция компонентов:** Поисковые адаптеры реализуются как изолированные модули, наследующие интерфейс `SearchAdapter`.
4. **Модульные тесты:** Любые изменения в `CommandParser`, `CommandRouter`, `DialogueManager` или `SearchTargetResolver` должны сопровождаться соответствующими модульными тестами в `app/src/test/`.
5. **Совместимость с пультом HDRC-BV1:** Новые возможности не должны нарушать логику аппаратного Push-to-Talk (PTT).
