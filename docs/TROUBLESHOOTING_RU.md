# Решение проблем (Troubleshooting) — VisionVoiceOffline

В этом документе собраны типичные неполадки при настройке и эксплуатации ассистента VisionVoiceOffline на телевизорах Huawei Vision S и способы их устранения.

---

## 1. Ошибки подключения ADB

### Симптом: `connection refused` или `unable to connect to 192.168.1.100:5555`
- **Причина:** Не включена отладка по сети в меню разработчика или неверно указан IP-адрес.
- **Решение:**
  1. Проверьте актуальный IP-адрес в «Настройки» $\to$ «Сеть».
  2. Убедитесь, что в «Настройки» $\to$ «Система» $\to$ «Для разработчиков» включён пункт «Отладка по USB / по сети».
  3. Проверьте, что компьютер и ТВ находятся в одной подсети (например, не подключены к изолированной гостевой Wi-Fi сети).

### Симптом: `device unauthorized`
- **Причина:** На экране ТВ не подтверждён ключ безопасности компьютера.
- **Решение:** Посмотрите на экран телевизора, установите флажок «Всегда разрешать с этого компьютера» и нажмите «ОК». Затем повторите команду `adb connect`.

---

## 2. Проблемы с захватом звука и кнопкой микрофона

### Симптом: При зажатии кнопки микрофона на пульте ничего не происходит
- **Причина:** Фоновая служба ассистента остановлена или пульт подключён только по инфракрасному каналу.
- **Решение:**
  1. Убедитесь, что пульт **HDRC-BV1** сопряжён с ТВ по **Bluetooth** (в меню «Bluetooth» телевизора пульт должен отображаться как подключённый).
  2. Запустите скрипт проверки состояния:
     ```powershell
     .\Check-VisionVoice.ps1 -DeviceIp 192.168.1.100
     ```
  3. Перезапустите службу ассистента:
     ```powershell
     .\Install-VisionVoice.ps1 -DeviceIp 192.168.1.100
     ```

### Симптом: Оверлей появляется, но пишет «Речь не распознана или тишина»
- **Причина:** Не выдано системное разрешение на доступ к аудиозаписи.
- **Решение:** Выполните команду:
  ```cmd
  adb shell pm grant com.huawei.vision.voiceoffline android.permission.RECORD_AUDIO
  ```

---

## 3. Проблемы с оверлеем

### Симптом: Команда выполняется, но всплывающая панель не отображается поверх YouTube или видео
- **Причина:** Заблокировано системное разрешение `SYSTEM_ALERT_WINDOW`.
- **Решение:** Активируйте AppOps через ADB:
  ```cmd
  adb shell appops set com.huawei.vision.voiceoffline SYSTEM_ALERT_WINDOW allow
  ```

---

## 4. Проблемы с системной навигацией («Домой», «Назад»)

### Симптом: На команду «Домой» оверлей сообщает о необходимости службы доступности
- **Причина:** `VisionVoiceAccessibilityService` отключена или была сброшена системой при перезагрузке.
- **Решение:** Запустите повторную привязку службы:
  ```cmd
  adb shell settings put secure enabled_accessibility_services com.huawei.vision.voiceoffline/com.huawei.vision.voiceoffline.VisionVoiceAccessibilityService
  adb shell settings put secure accessibility_enabled 1
  ```

---

## 5. Поведение после перезагрузки телевизора

При включённой опции «Автозапуск при загрузке ТВ» (в приложении «Настройки» $\to$ «Автозапуск») служба запускается автоматически при старте системы. Если этого не произошло, достаточно один раз открыть ярлык VisionVoiceOffline из списка приложений телевизора.

---

## 6. Сбор обезличенного отчёта для отправки на 4PDA

Если вы столкнулись с ошибкой и хотите обратиться за помощью в тему на 4PDA:
1. Запустите диагностику:
   ```powershell
   .\Check-VisionVoice.ps1 -DeviceIp 192.168.1.100 > report.txt
   ```
2. Откройте `report.txt`, убедитесь в отсутствии личных сведений.
3. Приложите текст отчёта под спойлер в вашем сообщении.
