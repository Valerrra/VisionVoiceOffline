# [APP][Android 10/HarmonyOS 2.0] VisionVoiceOffline — Автономный голосовой помощник для Huawei Vision S

[B][COLOR=royalblue]VisionVoiceOffline[/COLOR][/B] — полностью автономный голосовой ассистент для смарт-телевизоров **Huawei Vision S** (серия KANT-359). 
Работает без облачных сервисов Google и Яндекс: вся обработка речи и выполнение команд происходят локально на процессоре телевизора с использованием квантованной нейросетевой модели Sherpa-ONNX.

---

### [B]Ключевые особенности[/B]
- [B]100% автономность:[/B] Никакой голос не отправляется в интернет. Приложение полностью работоспособно даже при отключённой внешней сети.
- [B]Управление через оригинальный Bluetooth-пульт HDRC-BV1:[/B] Работа в режиме Push-to-Talk (PTT). Микрофон активен строго при удержании кнопки с микрофоном; в паузах между командами запись аппаратно отключена.
- [B]Глобальный всплывающий оверлей:[/B] Не перехватывает управление с пульта (D-pad) и не прерывает просмотр фильмов в полноэкранных плеерах.
- [B]Универсальный поиск по приложениям:[/B] Поддержка прямого поиска («Найди на Ютубе Варламова»), контекстного диалога с уточнением источника («Где будем искать?» $\to$ «В Лэйзи Медиа») и памяти последнего запроса (120 секунд) для повтора и уточнения сезонов («А теперь второй сезон»).
- [B]Системная навигация без системных привилегий:[/B] Выполнение команд «Домой», «Назад» и «Недавние» через изолированную службу специальных возможностей без чтения экранного содержимого.
- [B]Безопасность системы:[/B] Не требует Root, не отключает предустановленные приложения и не модифицирует системный Audio HAL.

---

### [B]Подтверждённые устройства[/B]
- **Huawei Vision S** (55", 65", 75", модель KANT-359).
- **HarmonyOS 2.0.0** (Android 10, API 29, ARM64-v8a).
- **Пульт:** Huawei HDRC-BV1 (Bluetooth).

---

### [B]Поддерживаемые команды[/B]
- [B]Громкость:[/B] «Громче», «Тише», «Громкость двадцать», «Звук на ноль», «Без звука».
- [B]Медиа:[/B] «Пауза», «Продолжить», «Стоп», «Следующий трек», «Предыдущий».
- [B]Системная навигация:[/B] «Домой», «Назад», «Недавние приложения».
- [B]Запуск/закрытие программ:[/B] «Открой Ютуб», «Запусти Лэйзи Медиа», «Закрой БайБай ДИПИАЙ», «Сверни».
- [B]Голосовой поиск:[/B]
  - «Найди на Ютубе [запрос]»
  - «Поищи в Лэйзи Медиа [название фильма/сериала]»
  - «Найди [название]» $\to$ «Искать в YouTube?» $\to$ «Да / В другом приложении»
  - «А теперь в Лэйзи Медиа» (повтор прежнего запроса)
  - «А теперь второй сезон» (уточнение сезона)
  - «Только на русском» / «С субтитрами»

### [B]Ограничения первой публичной бета-версии (v0.1.0-beta)[/B]
1. Первоначальная активация службы доступности и наложения требует однократного выполнения скрипта через ADB с компьютера.
2. Поддерживаются только приложения с документированными интерфейсами поиска (YouTube TV, LazyMedia Deluxe).
3. Распознавание оптимизировано под русский язык (Zipformer RU INT8).

---

### [B]Требуемые разрешения[/B]
- `RECORD_AUDIO` — захват звука с микрофона пульта при удержании PTT.
- `FOREGROUND_SERVICE` — удержание фонового сервиса ассистента в памяти.
- `SYSTEM_ALERT_WINDOW` — отображение полупрозрачной панели оверлея поверх других программ.
- `RECEIVE_BOOT_COMPLETED` — автозапуск после включения телевизора.
- `BIND_ACCESSIBILITY_SERVICE` — навигация «Домой» и «Назад».

### [B]Краткая инструкция по установке[/B]
1. Скачайте релизный архив `VisionVoiceOffline-v0.1.0-beta.zip`.
2. Включите отладку по сети в меню телевизора («Настройки» $\to$ «Для разработчиков» $\to$ «Отладка по USB/сети»).
3. Запустите на компьютере:
   ```powershell
   .\Install-VisionVoice.ps1 -DeviceIp 192.168.1.xxx
   ```
4. Подтвердите отладку на экране телевизора (галочка «Всегда разрешать»).

Подробная пошаговая инструкция с иллюстрациями: см. `docs/ADB_SETUP_RU.md`.

### [B]Сбор диагностического отчёта при ошибках[/B]
Если у вас возникли сложности, запустите скрипт проверки:
```powershell
.\Check-VisionVoice.ps1 -DeviceIp 192.168.1.xxx > report.txt
```
и приложите файл `report.txt` под спойлер в вашем ответе в теме.
