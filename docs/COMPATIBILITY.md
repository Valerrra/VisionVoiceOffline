# Таблица совместимости (Compatibility Guide)

В данном документе зафиксированы результаты фактического физического тестирования ассистента **VisionVoiceOffline**.

> **Важно:** Совместимость подтверждена строго для перечисленных конфигураций. Не гарантируется корректная работа на других моделях или версиях ОС без предварительного тестирования.

---

## 1. Подтверждённые устройства (100% Verified)

| Параметр | Подтверждённое значение |
|---|---|
| **Модель телевизора** | **Huawei Vision S** (KANT-359: 55", 65", 75") |
| **Операционная система** | **HarmonyOS 2.0.0** (базируется на Android 10, API 29) |
| **Аппаратная платформа** | HiSilicon Honghu 818 (ARM64-v8a) |
| **Оригинальный пульт ДУ** | **Huawei HDRC-BV1** (Bluetooth PTT) |
| **Источник звука** | `AudioRecord` (`address=back`, 16 кГц, 16 бит, моно) |
| **Служба навигации** | `VisionVoiceAccessibilityService` (HOME, BACK, RECENTS) |

---

## 2. Экспериментальные / Нетестированные конфигурации

| Устройство / Конфигурация | Статус | Комментарий |
|---|---|---|
| **Huawei Smart Screen SE / V / X** | Не тестировалось | Архитектура аудиодрайвера и код пульта могут отличаться. |
| **HarmonyOS 3.0 / 4.0** | Не тестировалось | Возможны дополнительные ограничения фоновых служб и AppOps. |
| **Сторонние Android TV приставки** | Не тестировалось | Приложение разрабатывалось под специфику Bluetooth-шины пульта Huawei HDRC-BV1. |
| **ИК-пульты без Bluetooth** | Не поддерживается | Передача аудиопотока по инфракрасному каналу невозможна. |
