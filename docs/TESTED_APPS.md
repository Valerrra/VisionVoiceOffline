# Таблица совместимости и проверенных приложений (Tested Apps)

В данном документе приведен официальный статус поддержки сторонних приложений и мультимедийных сервисов в **VisionVoiceOffline**.

> [!IMPORTANT]
> **Подтверждённая аппаратная и программная платформа:**
> - **Устройство:** Умный экран / телевизор **Huawei Vision S** (серия модели **KANT-359**, версии 55", 65", 75").
> - **Операционная система:** **HarmonyOS 2.0.0** (база **Android 10**, API уровень 29).
> - **Пульт управления:** Физический Bluetooth-пульт **Huawei HDRC-BV1** со встроенным микрофоном.
>
> *Внимание:* Совместимость с другими моделями телевизоров Huawei (Vision V, Vision Smart Screen, Vision SE и новыми версиями HarmonyOS 3/4) без проведения физических испытаний **не заявляется**.

---

## 1. Статус поддержки приложений

В системе разделены два уровня интеграции:
1. **Голосовой запуск (`APP_LAUNCH`):** Возможность запустить приложение голосовой командой («Открой [Имя]», «Запусти [Имя]») через динамический реестр `DynamicAppRegistry`.
2. **Полноценный голосовой поиск (`VOICE_SEARCH`):** Возможность открыть экран поиска целевого приложения, передать распознанный запрос и отобразить результаты («Найди в [Имя] [Запрос]»).

| Приложение | Имя пакета (Package Name) | Голосовой запуск | Полноценный голосовой поиск | Метод интеграции / Примечание |
|---|---|:---:|:---:|---|
| **YouTube TV** | `com.google.android.youtube.tv` | ✅ Подтверждено | ✅ **Подтверждено** | Leanback Deep Link `ACTION_VIEW` (`https://www.youtube.com/results?search_query=...`) |
| **SmartTube / SmartTubeTV** | `com.liskovsoft.videomanager`, `com.liskovsoft.smarttubetv.beta` | ✅ Подтверждено | ✅ **Подтверждено** | Поддерживается адаптером YouTube (совместимый Leanback Search URI) |
| **LazyMedia Deluxe** | `com.lazycatsoftware.lazymediadeluxe`, `com.lazycatsoftware.lmd` | ✅ Подтверждено | ✅ **Подтверждено** | Exported Intent `ActivityTvSearch` с параметром `query` |
| **Кинопоиск** | `ru.kinopoisk.tv` | ✅ Подтверждено | ⚠️ *Экспериментально* | Голосовой запуск работает штатно. Поисковый адаптер не подтвержден на физическом ТВ; при запросе поиска ассистент предлагает диалоговый выбор установленных альтернатив |
| **Lampa** | `lampa.app` / Web Wrapper | ✅ Подтверждено | ⚠️ *В разработке* | Исследуется возможность передачи параметров поиска через Deep Link |
| **HDRezka App** | `ag.app.hdrezka` | ✅ Подтверждено | ⚠️ *В разработке* | Поисковый интент в исследовании |
| **ByeByeDPI** | `ru.chelaxian.byebyedpi` | ✅ Подтверждено | ❌ Не применимо | Сервисная утилита. Поддерживается голосовой запуск и открытие настроек |
| **Wolf Launcher** | `com.wolf.firelauncher` | ✅ Подтверждено | ❌ Не применимо | Альтернативный домашний экран. Доступен быстрый запуск по голосовой команде |
| **Любые установленные приложения** | Произвольные пакеты | ✅ **Поддерживается** | ❓ Требует адаптера | Любое установленное приложение автоматически обнаруживается `DynamicAppRegistry` и может запускаться по имени |
